# 📚 Trabalho — Projeto Java

## 📝 Sobre o projeto

Este projeto foi desenvolvido como parte de um trabalho acadêmico, com o objetivo de colocar em prática os conhecimentos adquiridos em programação e desenvolvimento de software utilizando a linguagem Java.

## 🎯 Objetivos

- Aplicar conceitos fundamentais de programação.
- Desenvolver a lógica de programação.
- Praticar a organização e a estruturação de código.
- Utilizar ferramentas de desenvolvimento, como o Visual Studio Code e o Git.

## 🛠️ Tecnologias utilizadas

- **Java** — linguagem de programação.
- **Visual Studio Code** — ambiente de desenvolvimento.
- **Git** — controle de versão.
- **GitHub** — armazenamento e compartilhamento do código-fonte.

## 🚀 Como executar o projeto

1. Instale o Java JDK.
2. Abra a pasta do projeto no Visual Studio Code.
3. Configure as extensões necessárias para Java.
4. Abra o arquivo principal do programa.
5. Execute o código utilizando o botão **Run** do VS Code ou o terminal.
